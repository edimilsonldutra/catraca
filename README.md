# Catraca

Venda de ingressos para eventos pequenos, construída em modo agente a partir do brief da fundadora.
Em construção: o README completo chega com a última wave.

## Como rodar

Pré-requisitos: Linux ou macOS (ou WSL), Docker com Compose, Git e Node.js LTS.

```bash
npm run up      # sobe tudo, com a seed
npm run down    # derruba tudo
npm run gates   # typecheck, lint e testes
```
